# Java package registry — curated seed of top library package prefixes
# Source: Maven Central download statistics, updated 2026-04
# Run `scripts/refresh-package-registry.sh` to download updated lists
#
# Format: one package PREFIX per line (dot-separated, lowercase)
# Note: Java import paths are dotted class names ("com.fasterxml.jackson.databind.ObjectMapper").
#   This registry stores PREFIXES, not full class names.
#   An import is "known" when any registry entry is a dot-bounded prefix of the import.
#   E.g., "com.fasterxml.jackson" matches "com.fasterxml.jackson.databind.ObjectMapper".
#
# Standard library (java.*, javax.*, sun.*, com.sun.*, jdk.*) is always known — NOT listed here.
# jakarta.* is the Jakarta EE namespace (NOT stdlib) — included below.
#
# Slopsquatting examples this registry catches:
#   com.fasterxml.jakson       → flag, suggest com.fasterxml.jackson
#   com.google.guava2          → flag, suggest com.google.guava
#   com.springsecurity         → flag (edit distance too large for suggestion)
#   org.hibernat               → flag, suggest org.hibernate
